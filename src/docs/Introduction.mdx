### 🎨 Recursos Principais

<hr />

- **Múltiplos tipos de toast:** (`success`, `error`, `warning`, `info`, `promise`).
- **Posicionamento flexível:** (`top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center`, `bottom-right`).
- **Gestos de Arrastar (Drag to Dismiss):** Suporte nativo a ponteiros touch e mouse para fechar deslizando.
- **Suporte para fechamento:** Você define o tempo de duração do toast na tela.
- **Suporte a Temas:** Alternância nativa entre temas `light` e `dark`.
- **Totalmente Tipado:** Desenvolvido em TypeScript do zero.

### 🚀 Uso básico

<hr />

#### Exemplo 1: Toast básico de Sucesso

```tsx
import { ToastContainer, toast } from "toast-altas";

function App() {
  const onShowToast = () => {
    toast.success("Toast de sucesso", "Descriçao do toast de sucesso");
  };

  return (
    <div>
      <button onClick={onShowToast}>Show Toast Success</button>
      <ToastContainer theme="dark" position="bottom-right" />
    </div>
  );
}

export default App;
```

#### Exemplo 2: Toast de Promise

```tsx
import { ToastContainer, toast } from "toast-altas";

function App() {
  const fetchData = async () => {
    const response = await fetch("api_url_aqui");
    const data = response.json();
  };

  const onShowToast = () => {
    toast.promise(fetchData(), {
      pendingTitle: "Carregando...",
      pendingDescription: "Descrição carregando",
      resolvedTitle: "Resolvido",
      resolvedDescription: "Descrição resolvida",
    });
  };

  return (
    <div>
      <button onClick={onShowToast}>Show Toast Success</button>
      <ToastContainer theme="dark" position="bottom-right" />
    </div>
  );
}

export default App;
```
