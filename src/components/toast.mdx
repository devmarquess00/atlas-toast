# Toast

O componente **Toast** é utilizado para exibir mensagens temporárias de feedback para o usuário, contendo algumas variantes, sendo elas: (success, warning, info, error e promise).

<hr />

<br />

### 🟢 Toast de Sucesso

##### - Código de exemplo:

```tsx
import { toast } from "atlas-toast";

const onShowSuccessToast = () => {
  toast.success("Toast de sucesso");
};

<button onClick={onShowSuccessToast}>Show Toast</button>;
```
